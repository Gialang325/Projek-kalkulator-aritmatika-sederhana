# Projek-kalkulator-aritmatika-sederhana
<b>Projek kalkulator aritmatika sederhana menggunakan bahasa pemrograman C++ dengan berbasis string terminal</b>

Projek ini adalah projek kelompok 7 yang dibuat untuk memenuhi tugas mata kuliah semester 1 pemrograman dasar di <b>Universitas Borneo Tarakan</b>. Dengan dibuatnya projek ini maka diharapkan bahwa mahasiswa memahami fungsi fungsi dasar seperti operator, if-else, string, dan sebagainya pada C++.
